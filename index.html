4. Master Lagrangian & KKT Optimality Conditions

Augmenting the Aluminum 6061-T6 frame weight objective with the governing physics equalities—static equilibrium (\(h_1 = 0\)), modal vibration (\(h_2 = 0\)), and linearized buckling (\(h_3 = 0\))—together with the R1–R11 performance fences and design box bounds yields the Master Lagrangian:

\(\mathcal{L} = \sum_{e=1}^{8} \rho_{Al} A_e(d) L_e(d) + \lambda_{stat}^T (K(d)u - F) + \lambda_{vib}^T (K(d) - \omega_1^2 M(d))\phi + \lambda_{buck}^T (K(d) + \alpha_{cr} K_G(d,u))\psi + \sum_{i=1}^{11} \mu_i g_i + \sum_{j=1}^{23} [\mu_{lb,j}(d_{min,j} - d_j) + \mu_{ub,j}(d_j - d_{max,j})]\)

4.1 First-Order Karush-Kuhn-Tucker (KKT) Conditions

  1. Stationarity: Setting gradients of \(\mathcal{L}\) with respect to design variables \(d\) and state variables \(u\) to zero yields the design optimality condition and the coupled adjoint state equation:
    \(\nabla_d \mathcal{L} = \frac{\partial f}{\partial d} + \lambda_{stat}^T \left(\frac{\partial K}{\partial d}\cdot u - \frac{\partial F}{\partial d}\right) + \lambda_{vib}^T \left(\frac{\partial K}{\partial d} - \omega_1^2 \frac{\partial M}{\partial d}\right)\phi + \lambda_{buck}^T \left(\frac{\partial K}{\partial d} + \alpha_{cr}\frac{\partial K_G}{\partial d}\right)\psi + \sum \mu_i \frac{\partial g_i}{\partial d} - \mu_{lb} + \mu_{ub} = 0\)
    \(\nabla_u \mathcal{L} = \lambda_{stat}^T K(d^*) + \lambda_{buck}^T \alpha_{cr} \left(\frac{\partial K_G}{\partial u}\right)\psi + \sum_{i=1}^{11} \mu_i^* \left(\frac{\partial g_i}{\partial u}\right) = 0\)
  2. Primal Feasibility: All governing physics equations (\(h_1 = 0\), \(h_2 = 0\), \(h_3 = 0\)), performance constraints (\(g_i \le 0\)), and manufacturing bounds (\(d_{lower} \le d^* \le d_{upper}\)) hold simultaneously at \((d^*, u^*)\).
  3. Dual Feasibility: Inequality and box-bound Lagrange multipliers remain non-negative: \(\mu_i^* \ge 0\), \(\mu_{lb,j}^* \ge 0\), and \(\mu_{ub,j}^* \ge 0\).
  4. Complementary Slackness: \(\mu_i^* \cdot g_i(d^*, u^*) = 0\), \(\mu_{lb,j}^*(d_{min,j} - d_j^*) = 0\), and \(\mu_{ub,j}^*(d_j^* - d_{max,j}) = 0\). Strictly positive multipliers (\(\mu_i^* > 0\)) identify active design drivers such as Goodman fatigue (R2), vertical stiffness (R3), and tire clearances (R10–R11).

5. Adjoint Sensitivity Method for Gradient Computation

Evaluating constraint sensitivities across 23 design variables via finite differences requires 24 full FEA solves per optimizer iteration. Using implicit differentiation on \(h_1(d, u) = K(d)u - F(d) = 0\), the total derivative of any response functional \(g(d, u)\) is decoupled from state sensitivities \(\partial u / \partial d_k\) by solving one linear adjoint system per active response:

\(K^T(d)\lambda = -(\partial g / \partial u)^T \implies \frac{dg}{dd_k} = \frac{\partial g}{\partial d_k} + \lambda^T \left(\frac{\partial K}{\partial d_k} \cdot u - \frac{\partial F}{\partial d_k}\right)\)

Because the global stiffness matrix \(K\) is symmetric (\(K^T = K\)) and already factored during the primal solve, each adjoint vector \(\lambda\) requires only a single back-substitution, delivering exact analytical gradients at \(O(1)\) solve cost relative to the design dimension.
